# Привет, я Вадим Лилеков

### Веб-разработка и приложения на C# / .NET

Создаю учебные веб-приложения на Python и JavaScript и приложения для Windows на C#. В моих проектах есть работа с базами данных, авторизация и роли, интеграция с REST API, графические интерфейсы и игровая логика.

## Обо мне

Мой GitHub — коллекция учебных и курсовых проектов, в которых можно проследить путь от интерфейса до модели данных и обработки пользовательских действий.

- **Веб-приложения:** Flask, серверные шаблоны, формы, SQLAlchemy и MySQL.
- **Клиентская разработка:** JavaScript, работа с DOM, асинхронные запросы, фильтры и расчёты.
- **Приложения для Windows:** WPF и Windows Forms, редактор карт и игра с плитками.
- **Проектирование:** отдельные библиотеки логики, связи между сущностями, примеры State и Observer.
- **Другие работы:** C++, Qt, CMake и .NET MAUI.
